# UseKarma

UseKarma researches and builds evidence-based approaches to AI alignment: keeping increasingly capable intelligent systems corrigible, accountable to legitimate human intent, and subject to human authority. Its repositories provide research, governance, infrastructure, and experimental domains; none establishes a general solution to AI alignment.

**The ecosystem charter is a proposal awaiting human adoption.** The projects have different maturity levels; this introduction does not claim a deployed, production-ready ecosystem.

| Project | Architectural responsibility |
| --- | --- |
| [Faraday](https://github.com/usekarma/faraday) | Research, falsifiable experiments and knowledge lineage |
| [Karma](https://github.com/usekarma/karma) | Evidence governance and decision control |
| [Adage](https://github.com/usekarma/adage) | Infrastructure control architecture |
| [Adage-Fabric](https://github.com/usekarma/adage-fabric) | Event-processing fabric |
| Aegis | Independent consent-first care coordination; restricted synthetic prototype |
| Prudence | Independent financial/business scenarios; restricted synthetic prototype |
| [AWS configuration](https://github.com/usekarma/aws-config), [IaC](https://github.com/usekarma/aws-iac), [runtimes](https://github.com/usekarma/aws-lambda) | Separate desired-state, implementation/execution, and runtime responsibilities |
| [Engineering template](https://github.com/usekarma/agent-business-solution-template) | Specifications, quality gates and human readiness review |

Humans own purpose, values and consequential decisions. Evidence and uncertainty stay explicit. Consent and repository-specific security controls remain independent boundaries. No charter statement authorizes autonomous execution.

Read the proposed [charter](https://github.com/usekarma/.github/blob/docs/ecosystem-charter/CHARTER.md), [architecture](https://github.com/usekarma/.github/blob/docs/ecosystem-charter/ARCHITECTURE.md), and [capability assessment](https://github.com/usekarma/.github/blob/docs/ecosystem-charter/REPOSITORIES.md). These proposal links deliberately target the review branch; moving them to an adopted version requires human review.
