# UseKarma Ecosystem Charter

Status: **proposed initial charter; not adopted**. Human review and explicit adoption are required.

UseKarma develops systems that turn human purpose into explicit intent, testable knowledge, reviewable decisions, and controlled implementation. This repository is the permanent, version-controlled home for its proposed architectural charter.

## Read the proposal

| Document | Purpose |
| --- | --- |
| [Charter](CHARTER.md) | Mission, ownership, scope, and adoption status |
| [Architecture](ARCHITECTURE.md) | System responsibilities and interface boundaries |
| [Principles](PRINCIPLES.md) | Reasoning, verification, privacy, and invalidation requirements |
| [Repositories](REPOSITORIES.md) | Revision-scoped source assessment and capability limits |
| [Governance](GOVERNANCE.md) | Human review, amendment, authorization, and unresolved decisions |
| [Organization profile](profile/README.md) | Public introduction |

These documents propose shared architectural commitments. Existing practices, reported demonstrations, and future capabilities are labeled separately. They do not certify deployments or establish production readiness.

The repository contains documentation only. It has no dispatcher, cloud credentials, deployment workflow, policy executor, or private domain records. Creating it does not activate an integration. Its organization profile describes intent, not a completed ecosystem.

**STOP_FOR_HUMAN before adopting the charter as authoritative.** See [Governance](GOVERNANCE.md) for the explicit adoption record and repository-specific review boundaries.
